A voice studio that lives on your computer.

Turn text into natural speech, clone voices, make podcasts and dub videos. Resonant runs the models on your own machine, so it's free, it's private, and there's no limit on how much you make.

Recorded on an ordinary laptop with no graphics card. Click any word to jump to it.

Write a scene. Hear it performed.

Dialogue mode gives each line its own voice and puts natural gaps between speakers. Use it for podcasts, interviews, audio dramas and game scenes.

Add a pause or an emotion right in the text with tags like [pause 2s], and the voice follows them instead of reading them out.

Everything in one studio

Text to speech
28 English voices built in, plus 9 expressive voices in 10 languages that take directions like “whisper” or “sound excited”.
Voice cloning
Copy a voice from a 10-second recording, or describe a new one in words, accent and mood included, and Resonant designs it.
Dialogue
Write a script with several speakers and get one finished audio file.
Dubbing
Transcribe a video, translate it, re-voice it and export an MP4 you can post.
Audiobooks
Import an EPUB, a PDF or plain text, and narrate it chapter by chapter into one MP3.
Speech to text
Transcripts with a timestamp for every word, speaker labels and subtitle export.
Read any web page
A Chrome and Edge extension reads articles or selected text aloud with your voices.
Works with your AI apps
Connect Claude, Cursor and other MCP apps, then just ask: "read this aloud in George's voice" or "turn my notes into a podcast".
Voice changer
Re-voice a recording in another voice while keeping its timing and emotion.

What your computer can run

Resonant uses what your machine has. The more powerful it is, the more of the studio runs at full speed.

Any recent laptop

8 GB of memory, no graphics card

The 28 built-in American and British voices start speaking in about a second, and transcription runs faster than real time. Heart and George on this page are two of them.

16 GB of memory

Still no graphics card

Adds designed voices with any accent, cloning, other languages and dubbing. The accented voices on this page were made this way. Each of those took about a minute to make, so they suit clips you save rather than live reading.

An NVIDIA graphics card

6 GB of video memory or more

Everything runs 20 to 50 times faster. Expressive voices, cloning and dubbing feel as quick as the built-in voices.

Already using the ElevenLabs API?

Resonant speaks the same API. Point your app, script or plugin at your own computer instead, and it keeps working without per-character fees.

# Same request, different address
curl http://localhost:3000/v1/text-to-speech/af_heart \
  -H "Content-Type: application/json" \
  -d '{"text": "Hello from my own computer."}' \
  -o hello.mp3

Install Resonant

On Windows, download the app and install it like any other program. On a Mac or Linux, or to run the code yourself, it takes four steps in a terminal.

Download for Windows

64-bit Windows 10 or 11, about 200 MB. The installer isn't code-signed yet, so Windows may ask you to confirm it (More info → Run anyway), and PCs with Smart App Control turned on block it. Running from source works everywhere.

  1. Install Node.js

    Version 22.5 or later, from nodejs.org.

  2. Download Resonant

    Get the codeGet the code and open its folder in a terminal.

  3. Install and start it

    npm install
npm start

  4. Open the studio

    Go to 127.0.0.1:3000 in your browser. Each model downloads the first time you use it.

Clone only voices you have permission to use

Voice cloning is for your own voice, actors who have agreed to it, and characters you create. Using someone's voice without their consent can hurt them and break the law where you live. Resonant runs on your computer, so using it responsibly is up to you.
